# Simple Interest Calculator

## Introduction
A Simple Interest Calculator is a program used to calculate the simple interest on a principal amount for a given rate of interest and time period.

## Formula
Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time Period in Years

## Example
- Principal Amount = ₹10,000
- Rate of Interest = 5%
- Time = 2 Years

SI = (10000 × 5 × 2) / 100

**Simple Interest = ₹1,000**

## Features
1. Calculates simple interest easily.
2. Uses principal, rate, and time as inputs.
3. Displays the calculated simple interest.

## Conclusion
The Simple Interest Calculator is a useful tool for calculating interest on a principal amount using a simple mathematical formula.
This project demonstrates a simple interest calculation.
